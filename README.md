# Enlightened Armory

Reffect pack for Guild Wars 2. Requires https://github.com/Zerthox/gw2-reffect.

Dedicated Weapon UI to help more clearly see mechanics of the more recently-added weapons.

## Supported Weapons

- Elementalist Hammer
- Mesmer Spear
- Engineer Spear
- Thief Axe
- Thief Spear
- Guardian Spear
- Revenant Spear

## Planned

- Elementalist Pistol
- Ranger Mace
- Necromancer Spear
